# 点过程窗口

window时间以各自起点后的分钟表示，范围(0,T]且不重复，每窗起点前没有历史。development窗共享mu/alpha/beta，似然是各窗之和；external独立起窗，用冻结参数按其已发生事件更新条件强度，不重新拟合。

强度在事件自身发生前计算，t_i不含自身。每事件积分贡献到T为alpha/beta*(1-exp(-beta*(T-t_i)))，beta>0，开发空窗仍贡献-mu*T。beta网格按给定顺序，同目标候选取先列者；稳定约束alpha<=r_max*beta与alpha_bounds共同生效。mu正有限边界不是自动估出的下限。

背景份额与历史核份额只在事件时刻分解，分母必须与似然相同；父明细可流式。观测窗末无事件尾是右删失等待而非完整间隔，诊断经验分布只用事件间完整积分。domain只检查时刻和窗长度，不计算核、拟合或诊断。
